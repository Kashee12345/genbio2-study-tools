Part 1: Selection Island

Each generation the animals live, some are removed by selection, and the survivors breed. The histogram and the line graph update as the population evolves.

How the model works: each individual has a heritable (additive genetic) value plus a random environmental part; h² sets how much of the variation is heritable at the start. Survival falls off with distance from the best value for the environment (seed size for finches, background colour for beetles), more steeply with stronger drought or more predators. Survivors always refill the island (soft selection), so the population never dies out here. Offspring get the average of their two parents' heritable values plus random reshuffling; mutation adds new variation each generation. With no mutation, strong selection slowly uses up variation. Heritability shown in the readout is the current value and can drift as variation changes. Population size is 60, so there is some chance wobble. Generations are shown far faster than real life.
